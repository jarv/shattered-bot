# Room policy coverage

These source names are an offline coverage inventory, never runtime room IDs.
Decisions must use public geometry, hazards, actors and observed loot only.
Unknown resources and routes are deferred rather than assumed safe.

| Rooms | Policy |
|---|---|
| ArmoryRoom, TreasuryRoom | Safe observed loot/key routes; inspect equipment. |
| LibraryRoom, SecretLibraryRoom | Reachable scrolls; avoid collateral fire. |
| LaboratoryRoom, SecretLaboratoryRoom | Accessible supplies and observed crafting. |
| RunestoneRoom, SecretRunestoneRoom | Safe paths or fully budgeted protection. |
| GardenRoom, SecretGardenRoom | Respect challenge rules; no assumed regeneration. |
| MagicWellRoom, SecretWellRoom | Inspect public effects; no unknown-effect guesses. |
| CryptRoom, PitRoom | Reserve health and anti-wraith magic. |
| CrystalChoiceRoom, CrystalPathRoom, CrystalVaultRoom | Compare public rewards and budget keys. |
| PoolRoom | Verified invisibility round trips; avoid fish and unsafe banks. |
| SentryRoom | Fully observed enclosure, haste duration and safe endpoints. |
| StorageRoom | Isolated barrier burns only; never enter active fire. |
| MagicalFireRoom | Frost or bounded potion tests; verify removal before entry. |
| ToxicGasRoom | Observed immunity covering entry, interaction and return. |
| TrapsRoom, SecretChestChasmRoom | Budget flight and return interactions. |
| WeakFloorRoom | Public landmark, fall/bleed budget and observed landing/exit. |
| StatueRoom, SacrificeRoom | Avoid optional high-risk farming. |
| ShopRoom | Visit observed shops and prioritize useful supplies. |
| DemonSpawnerRoom | Suppress visible spawners while respecting minion threats. |
| SecretArtilleryRoom, SecretLarderRoom | Safe loot; avoid accidental bombs. |
| SecretHoardRoom, SecretSummoningRoom | Summoning/trap safety overrides treasure. |
| SecretHoneypotRoom | No dangerous bee release for marginal reward. |
| SecretMazeRoom | Bounded pathfinding; no assumed unseen layout. |
| RatKingRoom | Safe gold; no class-changing interactions. |
